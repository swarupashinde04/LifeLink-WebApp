# 🩸 LifeLink

**LifeLink** is an AI-powered emergency blood response web application developed using **Python** and **Streamlit**. The platform helps connect patients with suitable blood donors by prioritizing donors based on **blood group compatibility, availability, and location**.

🌐 **Live Demo:**  
https://lifelink-g53xksbxwae4qrjhzwkdlb.streamlit.app/

---

## ✨ Features

- ❤️ Donor Registration
- 🚑 Emergency Blood Request
- 🤖 AI-Based Donor Prioritization
- 📊 Dashboard with Donor & Request Statistics
- 🔄 Update Donor Availability
- ✅ Form Validation

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/swarupashinde04/LifeLink-WebApp.git
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
streamlit run Home.py
```
